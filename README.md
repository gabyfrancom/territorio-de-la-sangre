# Sangre, Territorio

App personal de seguimiento de anticoagulación con acenocumarol (Sintrom): INR, pauta, diario, incidencias e interacciones con alimentos, bebidas, medicamentos y suplementos.

100% estática (HTML/CSS/JS), sin backend. Los datos viven en el navegador de cada dispositivo (`localStorage`) — nada se sube a ningún servidor.

Ver [LEEME.md](./LEEME.md) para instrucciones de uso e instalación como app.
